<h1 align="center">DeepSeek Chat</h1>

<p align="center"><strong>在 DeepSeek Harness 中，一键切换网页聊天与原工作区。</strong></p>

<p align="center"><strong>简体中文</strong> · <a href="README.en.md">English</a></p>

---

DeepSeek Chat 是一款 **DSH 桌面插件**：选择 **CHAT** 在 DSH 内使用真实的 [DeepSeek Chat 官网](https://chat.deepseek.com/)；选择 **HARNESS** 随时回到原来的工作区。插件不接管你的账号体系，官网登录独立保存。

当前发布版 **0.2.23** · 适用于 **DSH 桌面版** · CHAT 网页的语言、外观和字号跟随 DSH。

## 核心功能

- **CHAT / HARNESS 一键切换**：在左上角品牌旁切换，侧栏显示官网对话列表、置顶与日期分组。
- **快捷键切换**：默认按 `Tab` 在两个模式间来回切换，也可自定义两个快捷键。
- **网页缓存策略**：缓存网页、延迟释放或立即释放，自行权衡切换速度与开发者工具（F12）。
- **附件下载**：代码块、图片与常见附件可保存到本机；外链交给系统默认浏览器。
- **外观跟随**：语言、明暗主题和内容字号跟随 DSH，无需重复设置。

## 如何更好地使用

这个插件最适合的工作流是 **“先聊透，再动手”**：

1. 切到 **CHAT**，先在官网聊天里把方案聊清楚（这一步不消耗 Harness 的 Token）。
2. 复制结论、方案文本或分享链接。
3. 用快捷键切回 **HARNESS**。
4. 把结论粘贴给 Agent，让它直接按确认的方案开发。

这样做的好处：

- **省 Token**：方案讨论发生在官网聊天里，不占用 Harness 上下文。
- **省上下文**：只把确认后的结论交给 Agent，减少来回澄清和无关历史。
- **更精准**：Agent 拿到的是已经定稿的方案，而不是几十轮试错过程。

两个典型场景：

- **需求梳理**：先在 CHAT 里让官网模型帮你拆需求、对比方案，定稿后切回 HARNESS 直接开发。
- **报错排查**：把错误贴进 CHAT 问清楚原因和修法，再把结论带回 HARNESS 让 Agent 改代码。

## 快速开始

1. 安装插件（见下方“安装”），**完整退出并重新打开 DSH**。
2. 切到 **CHAT**，点击 **登录 DeepSeek**，在插件内的官网页面正常登录。
3. 登录后账号与对话列表会自动同步；**设置 → Chat 设置** 可查看账号、退出登录和调整偏好。
4. 需要回到原工作区时切换到 **HARNESS**，原来的面板会恢复。

## 安装

### 按名称安装（当前发布版）

在 DSH 插件安装输入框中输入：

```text
dsh-deepseek-chat@0.2.23
```

或使用命令行：

```bash
dsh plugin --profile desktop add dsh-deepseek-chat@0.2.23
```

### 从 GitHub 安装

```text
https://github.com/xingxingbk-git/dsh-deepseek-chat
```

```bash
dsh plugin --profile desktop add https://github.com/xingxingbk-git/dsh-deepseek-chat
```

此方式安装仓库中已推送的版本；需要系统已安装 Git，Windows 可先安装 [Git for Windows](https://git-scm.com/install/windows)，再重开 DSH。

### 使用本地安装包

```bash
dsh plugin --profile desktop add /absolute/path/dsh-deepseek-chat-0.2.23.tgz
```

安装或更新后请**完整退出并重新打开 DSH**。使用其他配置环境时，把命令中的 `desktop` 换成对应名称。

## 功能说明

### CHAT 与 HARNESS

![CHAT 模式：DSH 侧栏与 DeepSeek 官网聊天页面](<docs/images/chat-overview.png>)

- CHAT 内嵌官网聊天：侧栏浏览对话、搜索、打开历史会话，顶部“新会话”开始聊天。
- 对话右侧菜单可重命名、置顶、分享和删除；点击“对话”右侧刷新图标更新网页与列表。
- 切回 HARNESS 恢复之前的主面板，再进 CHAT 会回到刚才的网页（取决于缓存策略）。

### 官网登录

CHAT 使用官网自己的登录流程，插件不读取密码或 Cookie。Google、Apple、微信、企业 SSO 等第三方登录都会在插件内显示对应的官方登录页，完成后自动回到 DeepSeek 聊天；普通账号密码登录也可正常使用。登录记忆只保存官网授权所需的最小信息，并按 DSH 配置环境隔离。

> 已知问题：有人反馈使用普通账号密码登录时偶发空白页或报错，目前未复现、原因未确认。如遇到，请重试或改用其他登录方式，并反馈系统和 DSH 版本。

### 模式切换器

![文字样式：CHAT 与 HARNESS 模式切换按钮](<docs/images/mode-switch-text.webp>)

**设置 → Chat 设置 → 切换按钮** 提供文字样式与图标样式。文字样式下两个按钮的文案都可自定义（最多 10 列宽，全角字符按 2 列计），保存后生效；侧栏较窄时自动截断，悬停显示完整内容。

### 快捷键

**设置 → Chat 设置 → 快捷键**：

- 开关默认开启；开启后显示左侧、右侧两个快捷键输入框和保存按钮，修改后点击保存生效。
- 默认两个都是 `Tab`，按 `Tab` 在两个模式间来回切换；两个设置为不同键时，左侧切到 CHAT、右侧切到 HARNESS。
- 支持组合键（如 `Ctrl+Shift+X`；macOS 上 Meta 键显示为 `Cmd`）；点击输入框后直接按组合键即可捕获，`Esc` 取消，`Backspace` 清空。清空后框内会提示补全，保存按钮不可用。
- 两个快捷键相同时是**有意设计**：按一下切换一次，不算冲突。
- 快捷键只在 DSH 窗口聚焦、且焦点不在输入框或其他可编辑区域时生效；**CHAT 网页内的按键由官网自己处理**，不会触发插件快捷键（网页内请用左上角切换按钮，或先点回 DSH 界面）。
- 捕获时如果该组合被系统或浏览器保留，输入框会提示冲突，且不会写入这个组合。
- 标题旁的 `?` 可以查看作用范围说明。

### 缓存策略

**设置 → Chat 设置 → 缓存策略** 三种策略：

| 策略 | 切回 CHAT | 开发者工具（F12） |
| --- | --- | --- |
| 保持缓存（默认） | 无需等待加载 | 网页存在期间不可用 |
| 立即释放 | 会重新加载 | HARNESS 下可用 |
| 延迟释放 | 设定秒数内无需加载 | 超时释放后可用 |

延迟释放可填 5–3600 秒，兼顾切换速度与开发者工具。

### 下载与外链

- 代码块 “下载”、Mermaid 导出的 SVG/PNG/代码、图片以及常见附件（PDF、Office、压缩包、音视频等）可保存到本机，单文件上限 16 MB。
- 对话中的外部链接使用系统默认浏览器打开；失败时只显示非阻断提示。
- 右键“另存为”、CHAT 网页内上传文件、麦克风等能力受 DSH 宿主限制。
- 附件保存依赖 DSH 的文件保存能力；在较旧的 DSH 版本上附件下载可能不可用（会提示失败），其余功能正常。

## 限制

- 仅支持 **DSH 桌面版**；兼容范围见下方“兼容范围”，暂不支持 DSH Web。
- 快捷键仅在 DSH 窗口聚焦、且焦点不在输入框或其他可编辑区域时生效，不能注册系统级全局快捷键；CHAT 网页内的按键由官网处理，不会触发插件快捷键。
- 保持缓存期间开发者工具（F12）不可用；需要 F12 请选择立即释放或延迟释放。
- 下载只接管用户点击的常见格式且单文件不超过 16 MB；右键另存为、iframe 内下载、程序化下载不接管。
- 文件上传对话框、麦克风等设备权限由 DSH 宿主控制，插件无法放开。
- 侧栏品牌与“新会话”适配依赖官方界面结构；同时安装其他侧栏 UI 插件时可能进入兼容模式（可在 Chat 设置恢复提示）。
- 官网页面结构变化可能影响账号或对话列表识别；插件会显示状态或兼容提示，可重试。
- 插件不读取聊天正文、Cookie、密码或 DSH 令牌；详见“隐私与数据”。

## 隐私与数据

聊天内容和账号历史由 DeepSeek 官网处理。插件为显示账号与导航，只读取官网可见的昵称、对话标题、分组和链接，且仅在当前登录期间保留于内存。

登录记忆只保存官网授权所需的最小信息，通过 DSH 官方凭据服务管理，并按配置环境隔离；退出登录会清除本插件的登录记忆。

插件不会把密码、Cookie 或聊天正文写入登录记忆，不读取 DSH 或其他插件的令牌，也不访问其他浏览器的登录数据。

## 兼容范围

适配当前最新的 **DSH 桌面版 0.2.2 发布线**（含各 RC 与正式版）。DSH 更新到 0.2.3 及以上版本时，插件需要重新适配。

## 卸载

在 DSH 插件管理器中移除，或执行：

```bash
dsh plugin --profile desktop remove dsh-deepseek-chat
```
